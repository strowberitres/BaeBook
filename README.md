# BaeBook
BaeBook 💖

A fun web project where you can "rent a girlfriend" (for entertainment purposes only).

BaeBook is a light-hearted, web-based application created purely for fun. The site allows users to browse and choose their desired “girlfriend” and subscribe to different subscription plans.

🚀 Features

Browse & select a girlfriend
Subscribe to different subscription plans
Fun and interactive user experience
Built with PHP
Hosted locally using XAMPP

🛠️ Technologies Used

PHP
HTML / CSS / JavaScript
XAMPP (local server)

💡 How to Run Locally

Install XAMPP
Place the project folder in htdocs
Start Apache and MySQL
Open your browser and go to:
http://localhost/BaeBook
